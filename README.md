# 🚗 GTAA444 - Cloud Vice City

> **2D Top-Down Retro Action Game**, созданная ИИ для GitHub Codespaces и браузера.

---

## 🎮 Как играть прямо в браузере

1. Откройте проект в **GitHub Codespaces** (или запустите расширение **Live Server**).
2. Либо перейдите в **Settings** -> **Pages** -> выберите ветку `main` -> нажмите **Save**. Игра будет доступна онлайн!

---

## 🕹 Управление (Controls)

| Действие | Клавиши |
|---|---|
| **Ходьба / Движение** | `W`, `A`, `S`, `D` или Стрелки |
| **Прицел** | Движение мыши |
| **Стрельба / Удар** | `Левая кнопка мыши` или `Пробел` |
| **Сесть в авто / Выйти** | `F` или `Enter` |
| **Управление машиной** | `W` (газ), `S` (задний ход / тормоз), `A` / `D` (руль) |
| **Дрифт / Ручник** | `Shift` или `Пробел` |
| **Клаксон (сигнал)** | `H` |
| **Смена оружия** | `1` (Кулаки), `2` (Пистолет), `3` (Микро-SMG Узи) |
| **Возрождение (при гибели)** | `R` |

---

## 🌟 Особенности игры

* **Синтезированный звук (Web Audio API)**: Звуки стрельбы, сирен, визг шин при заносе, двигатели и удары без внешних файлов!
* **Уровень розыска (Звёзды)**: Совершайте преступления, чтобы привлечь полицию. Полицейские перехватчики преследуют нарушителей с сиренами и мигалками!
* **Живой город**: Дорожная сетка, здания с вертолётными площадками, пешеходы, падающие пачки наличных ($).
* **Автомобили**: Седаны, спорткары, грузовики и патрульные машины с реалистичной физикой дрифта и следами шин на асфальте.
